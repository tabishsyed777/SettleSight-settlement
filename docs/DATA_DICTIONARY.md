# SettleSight data dictionary

All values in the shipped files are generated by src/build.py. Identifiers resemble examples
only; they do not identify real trades or institutions.

## Trade features

| Feature | Meaning in the simulator | Dashboard explanation |
|---|---|---|
| cp_fail_rate | Generated counterparty historical failure rate | Counterparty fail history |
| illiquidity | Generated security illiquidity score from 0 to 1 | Security illiquidity |
| ssi_missing | 1 when the simulator marks settlement instructions missing or mismatched | SSI missing or mismatched |
| affirm_delay_h | Generated affirmation delay in hours | Affirmation delay |
| hrs_to_cutoff | Simulated hours remaining to settlement cutoff | Time left to cutoff |
| size_pressure | Simulated trade size relative to daily security volume | Trade size vs daily volume |

## Main output files

### data/synthetic_output.json

- kpi: book counts, risk totals, expected costs, estimated savings, model AUC, base rate,
  liquidity breach hours, and the simulated time/cutoff.
- trades: scored simulated trades, risk band, suggested action, cost estimate, and top
  feature contributions.
- liq: hourly expected cash flows, balance, and stress balance.
- thr: simulated minimum liquidity buffer.
- coll: greedy and baseline collateral allocations with costs.
- audit: alerts for high-risk trades.
- model: synthetic model weights, bias, and AUC.

### data/audit_log.jsonl

One JSON object per high-risk dashboard alert. Fields include timestamp, synthetic trade ID,
model label, score, action, explanation strings, and status.

### dist/index.html

A standalone HTML file containing the dashboard template and a snapshot of the generated
scenario. It has no runtime API connection and makes no network requests for data.

## Cost and action assumptions

The script calculates a simple cost rate from an illustrative penalty, one day of funding at
5%, and an operations cost. Estimated savings apply a fixed 70% rescue assumption to
non-LOW trades. These values are demonstration parameters, not market quotes or measured
operational outcomes.
